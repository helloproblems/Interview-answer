我看到了一系列数据，可用于数据模型进行标签(真故障、误报故障)训练。

## 做了什么
    让模型基于原数据进行去重、无效(未上报)数据后，将数据拆成三份，训练集、测试集、验证集。并让模型使用训练集、测试集进行数据模型的训练。
    训练完成后，由我使用验证数据集进行验证。

原始 961 行去除 46 条完全重复记录，再排除 46 条未回传标签记录，保留 869 条有效数据。按时间拆为训练集 498 条、测试集 129 条、验收验证集 242 条。

模型和阈值只在训练集内部选择；测试集用于评估，不参与训练。训练完成后，由我使用验证数据集验收。

## 怎么证明有用
    用验证数据集进行验证。

用验证数据集进行验证。

```bash
uv run --locked python -m scripts.evaluate --input datasets/validation.csv --output-dir outputs/user_acceptance
```

命令会显示中文结果摘要，并在本地 `outputs/user_acceptance/` 下生成 `report.html`（验收页面）、`summary.md`（文字摘要）和 `validation_details.csv`（逐单明细）。运行后用浏览器打开 `report.html`，可筛选漏判、分类错误与复核工单，也可搜索工单、片区或设备。生成结果未随本次代码提交。
