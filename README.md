## 复现步骤

使用 [uv](https://docs.astral.sh/uv/getting-started/installation/) 管理项目。Python 版本为 3.10（由 `.python-version` 指定）；直接依赖见 `pyproject.toml`，完整依赖版本锁定在 `uv.lock`。

安装 uv 后，在仓库根目录执行：

```powershell
uv sync --locked
uv pip check
uv run --locked python -c "import pandas, numpy, matplotlib; print('Environment OK')"
```

`uv sync --locked` 创建或同步 `.venv`，并检查锁文件与项目配置一致；无需手动激活环境。新增或移除依赖使用 `uv add <包名>`、`uv remove <包名>`，同时提交更新后的 `pyproject.toml` 和 `uv.lock`。运行分析脚本使用 `uv run --locked python <脚本路径>`。
