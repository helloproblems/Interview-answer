# 答题说明

## 我的判断

我看到了一系列数据，可用于数据模型进行标签(真故障、误报故障)训练。

## 做了什么

原始 961 行去除 46 条完全重复记录，再排除 46 条未回传标签记录，保留 869 条有效数据。按时间拆为训练集 498 条、测试集 129 条、验收验证集 242 条。

模型和阈值只在训练集内部选择；测试集用于评估，不参与训练。训练完成后，由我使用验证数据集验收。

## 怎么证明有用

用验证数据集进行验证。

```bash
uv run --locked python -m scripts.evaluate --input datasets/validation.csv --output-dir outputs/user_acceptance
```

命令会显示中文结果摘要，并在本地 `outputs/user_acceptance/` 下生成 `report.html`（验收页面）、`summary.md`（文字摘要）和 `validation_details.csv`（逐单明细）。运行后用浏览器打开 `report.html`，可筛选漏判、分类错误与复核工单，也可搜索工单、片区或设备。生成结果未随本次代码提交。

### 当前验证结果怎么读

以下数字来自已有的本地 `metrics.json`（原始指标）与 `predictions.csv`（逐单预测），可用上述验收命令复现。此次只改善展示，没有重新训练、推理或根据验证集调整阈值。

| 观察项 | 结果 | 判断依据 |
| --- | --- | --- |
| 验证样本 | 242 条 | 真实故障 220 条，空跑 22 条 |
| 准确率 | 90.08% | 全部判为故障的基线为 90.91%，模型低 0.83 个百分点 |
| 真故障召回率 | 97.73% | 识别 215/220，漏判 5 条；95% Wilson 区间 94.79%～99.03% |
| 空跑识别率 | 13.64% | 识别 3/22，仍有 19 条未识别 |
| 预测无故障的正确比例 | 37.50% | 8 条预测无故障中，仅 3 条实际无故障 |
| ROC-AUC | 0.8701 | 显示一定排序能力，不证明当前阈值满足业务要求 |

**当前不能仅凭“90% 准确率”认定模型有效。** 分类阈值为 0.50；复核阈值为 0.60，建议复核 21 条，其中空跑 9 条、真实故障 12 条。应作为人工复核建议，不自动撤单。

按题目口径，复核成本为 `21 × 12 = 252` 工时；若其中空跑成功拦截比例为 `q`，潜在净工时为 `9 × 120 × q − 252`。`q=50%` 时为 288 工时，`q=100%` 时为 828 工时；这是假设估算，尚未计入故障延误、误清除损失。页面滑块用于对比这些情景。

验收结论由用户决定。末两天数据曾在初版中被查看，不能视为完全未见的盲测；小样本、缺失回传和未来分布变化也限制了结论。

### 仅刷新展示与检查

已有验收结果时，仅重新生成展示，不需再次评估验证集：

```bash
uv sync --locked
uv run --locked python -m scripts.report --output-dir outputs/user_acceptance
uv run --locked python -m unittest discover -s tests -v
```

报告生成前会核对原始指标、逐单预测和固定阈值是否一致，并保留原始文件。测试使用合成数据检查行为，不作为模型效果依据。
